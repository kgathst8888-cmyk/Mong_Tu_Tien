MONG TU TIEN - BAN MODULAR CO THE CHOI
======================================

CACH DE NHAT (Windows):
1. Giai nen ZIP.
2. Mo file PLAY_GAME.bat.
3. Trinh duyet se tu mo game.

Neu may co Python 3, PLAY_GAME.bat se tu dong chay local server de game co moi quyen web can thiet.
Neu khong co Python, file nay se thu mo index.html truc tiep.

CACH THU CONG:
- Mo index.html bang Chrome/Edge.
- Hoac chay: python -m http.server 8765
  sau do mo: http://127.0.0.1:8765/index.html

CAU TRUC:
assets/    = Base64 anh/font, tach rieng
core/      = engine + error handler
combat/    = he thong chien dau
world/     = ban do, boss, lang, khai thac...
systems/   = save/cloud/input/farming...
equipment/ = trang bi/shop
ui/        = giao dien

QUAN TRONG:
Khong doi ten file/thu muc neu khong cap nhat index.html.
Khong dua Base64 vao module gameplay.
Khong xoa asset cu khi them tinh nang.
